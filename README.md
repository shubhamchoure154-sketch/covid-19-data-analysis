# COVID-19 Data Analysis using Python

## Project Overview
This project analyzes COVID-19 data to explore confirmed cases, deaths, and recoveries. The goal is to understand trends in the pandemic and derive meaningful insights through data analysis and visualization.

## Objectives
- Analyze confirmed COVID-19 cases, deaths, and recoveries.
- Calculate death rate and recovery rate.
- Explore trends and patterns in the dataset.
- Visualize key findings to support data-driven understanding.

## Tools & Technologies
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Jupyter Notebook

## Dataset
The project uses a cleaned COVID-19 dataset containing information about confirmed cases, deaths, and recoveries.

## Analysis Performed
- Data loading and inspection
- Data quality and missing-value checks
- Death rate calculation
- Recovery rate calculation
- Exploratory data analysis
- Data visualization and trend analysis

## Key Metrics
- **Death Rate:** Deaths / Confirmed Cases × 100
- **Recovery Rate:** Recovered Cases / Confirmed Cases × 100

## Project File
`COVID-19 Cleaned.ipynb`

The Jupyter Notebook contains the analysis, calculations, visualizations, and findings.

## Conclusion
This project demonstrates how Python can be used to analyze public health data, calculate meaningful metrics, identify trends, and communicate insights through visualizations.

## Skills Demonstrated
Python, Pandas, data cleaning, exploratory data analysis (EDA), data visualization, and analytical thinking.
